01 / START WITH THE EVIDENCE

One report.
Concrete next steps.

Diagnosis collects measurements and guidance. It does not run repairs or cleanup.

01

Storage and load

Collect free space, temporary files, Recycle Bin and memory data. A bounded CPU and drive sample adds a snapshot of current load.

02

Startup and maintenance

Summarise startup entries, pending restarts and available Windows updates. Further maintenance remains a deliberate decision.

03

A local report

Save a JSON report and readable console guidance. Known folders and browser caches are measured but not cleaned automatically.

02 / THE CLEANUP SCOPE

Two actions.
Reviewed separately.

Remediate validates the report, computer and user, then measures the cleanup scopes again before offering actions.

ActionOffered aboveScope
CleanTempFiles500 MBCurrent user’s temp folder. Locked files are skipped.
CleanRecycleBin500 MBCurrent user’s Recycle Bin on local fixed drives. Items cannot be restored from the Recycle Bin afterwards.
Other findings are guidance. These cleanup actions do not change startup apps, updates, security software, personal files or browser caches. The tool is not a registry cleaner or an automatic debloater.
03 / STEP BY STEP

Diagnosis. Preview.
Your decision.

Extract the ZIP

Download the ZIP, compare its checksum and extract it. Open PowerShell in the extracted project folder.

Run diagnosis

Run the diagnosis command. It writes a JSON report into your resolved Documents folder.

Review the preview

Set the path to the newly generated report and first run Remediate with -WhatIf.

Choose deliberately

Run Remediate without -WhatIf only after reviewing it. Confirm each offered action individually.

01 · Diagnosis without changes

.\windows-makeover.ps1 -Mode Diagnosis

02 · Replace the report filename with the one created by diagnosis

$reportPath = Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'WindowsMakeover\reports\diagnosis-YYYYMMDD-HHMMSS.json'
.\windows-makeover.ps1 -Mode Remediate -ReportPath $reportPath -WhatIf

03 · After review, with individual confirmation

.\windows-makeover.ps1 -Mode Remediate -ReportPath $reportPath

Requirements

Windows PowerShell 5.1 or PowerShell 7+. Supported cleanup actions do not require administrator privileges.

Beta and older systems

Target systems range from Windows 7 SP1 to Windows 11. Broad testing on real PCs is still pending. Older systems may lack individual probes; Windows 7 needs PowerShell 5.1 installed beforehand.

GOOD TO KNOW

Before you start.

Does the tool promise a faster PC?

No. It supports initial diagnosis and limited cleanup. It cannot reliably rule out hardware faults, overheating, malware or driver problems.

What does -WhatIf do?

It previews the intended cleanup actions without deleting files. Since no cleanup starts, it also creates no remediation audit entry.

Can I share the report?

Review it first. Reports stay local but contain information including computer name, user SID, process and startup names, folder paths and system status. Remove information you do not want to share.

Do I need to change the global execution policy?

No. Review the script and, if needed, unblock only that file through its properties or Unblock-File. The README describes the process.
